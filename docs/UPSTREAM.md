# Upstream backends

LordSU supports two configured upstream source families:

- KernelSU: https://github.com/tiann/KernelSU.git (default branch: main)
- KernelSU Next: https://github.com/KernelSU-Next/KernelSU-Next.git (default branch: dev)

Both upstream repositories are GPL-3.0. LordSU must preserve applicable license notices and attribution when distributing derivative source.

LordSU does not make the upstream Manager APK a runtime dependency. The product goal is an independent manager UI/backend adapter.
